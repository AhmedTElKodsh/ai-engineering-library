AI Engineering Core Glossary

A compact reference for the main-track language we will use while learning.

Term Working meaning Why it matters
Deterministic baseline A version of the workflow that works without model behavior. It gives you something testable before adding probabilistic output.
Provider boundary A wrapper around model calls that controls inputs, outputs, errors, timeouts, and cost traces. It keeps model behavior from leaking everywhere in the codebase.
Tool contract An explicit schema and permission boundary for work an AI system may request. It prevents unvalidated model text from becoming authority.
RAG Retrieval-augmented generation: retrieve evidence first, then answer from that evidence. It makes answers inspectable and gives the system a reason to abstain.
Trace A structured record of what the workflow did at each step. It lets another engineer debug success, refusal, retries, and failure.
Evaluation A repeatable check of behavior against examples, expected failures, or quality rules. It turns "seems good" into evidence.
Agentic workflow A workflow that can plan, call tools, review results, or hand off tasks within explicit limits. It is powerful only when state, tools, permissions, and stop conditions are visible.
