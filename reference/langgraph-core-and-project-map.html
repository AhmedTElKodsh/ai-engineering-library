LangGraph Core And Project Map

A compact reference for the FinAgent Research Brief Workflow project.

The Small Mental Model

TermMeaningProject example
StateThe current raw facts shared across steps.Request, route, evidence, draft, approval status.
NodeA Python function that reads state and returns updates.Classify request, retrieve evidence, draft brief.
EdgeThe rule selecting which node runs next.Research requests retrieve; advice requests refuse.
ReducerThe rule for combining an update with existing state.Append trace events instead of overwriting them.
GraphThe compiled state, nodes, and routing rules.The runnable research-brief workflow.
CheckpointA saved state snapshot at a step boundary.Resume a draft after review or failure.
ThreadThe identifier tying checkpoints to one run history.One research request and its revisions.
InterruptA deliberate pause awaiting external input.Human approval before publishing the brief.

State stores raw facts. Prompt strings and display formatting are derived inside nodes when needed.

Project Route

START
  -> classify_request
       -> refuse_request -> END
       -> retrieve_evidence -> draft_brief -> review_brief
            -> revise_brief -> review_brief
            -> publish_brief -> END

The first version is deterministic and local. Model calls, tools, persistence, and human review arrive only when the underlying contract is visible and tested.

Eight Increments

IncrementTangible winEvidence
1. BlueprintMap state, nodes, edges, and stop paths.Defensible graph sketch.
2. First graphRun deterministic research/refusal routes.Two passing assertions.
3. State updatesAdd trace history with a reducer.No overwritten events.
4. Model boundaryReplace classification with structured model output.Stubbed unit test plus one live trace.
5. Tool boundaryRetrieve citation-ready evidence.Tool failure and abstention tests.
6. PersistenceResume the same run from a checkpoint.Stable thread ID and state readback.
7. Human reviewPause, edit, approve, and resume safely.Interrupt/resume demonstration.
8. Production proofStream, test, and explain failure boundaries.Portfolio-ready trace and short architecture defense.

Framework Decision Rule

Use plain Python when a short function or fixed sequence is enough. Reach for LangGraph when the workflow genuinely needs inspectable state transitions, branching or loops, durable resume, streaming progress, or human intervention.
