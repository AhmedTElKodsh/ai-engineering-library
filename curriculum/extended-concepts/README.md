# Extended Concepts: After Milestone 1

This folder holds valuable deepening labs that should not slow down the
30-45-hour AI Application Implementer milestone. Use these after the related
main capability works, after the matching evidence gate exists, or when a
learner has a project reason to go deeper.

Run commands from the repository root unless a lesson says otherwise.

Expected effort: most extended concept labs take 4-6 focused hours. Treat them
as optional deepening blocks, not hidden prerequisites for the main timeline.
If an extended lab threatens a milestone date, return to the main-track
artifact and schedule the extension later.

## Recommended Order

| Order | Folder | Return here after | Why delay it |
| ---: | --- | --- | --- |
| 1 | `01-model-internals/week-01-tiny-transformer` | Milestone 1 retrieval/mechanism evidence | It deepens model mechanics, but the first milestone needs only enough internals for API/RAG/system decisions. |
| 2 | `01-model-internals/week-02-training-vs-inference` | Milestone 1 evaluation and model-choice evidence | Training math is useful later; the first milestone needs the adaptation decision boundary. |
| 3 | `02-agentic-systems/week-01-framework-state-machine` | one explicit plain-Python workflow passes | Framework state is easier after visible workflow state is understood. |
| 4 | `02-agentic-systems/week-02-resumable-orchestration` | bounded retry and stop-condition evidence | Resume depth is useful for production, not the first bounded workflow. |
| 5 | `02-agentic-systems/week-03-multi-role-collaboration` | Milestone 2 project need | Multi-role work can distract from simpler verification. |
| 6 | `02-agentic-systems/week-04-production-multi-agent-boundaries` | reliable single-workflow operation | Multi-agent boundaries belong after single-workflow reliability. |
| 7 | `03-production-depth/week-01-reproducible-package` | one tested local service boundary works | Packaging depth belongs to production engineering. |
| 8 | `03-production-depth/week-02-model-adaptation` | strong task-specific evaluation evidence | Fine-tuning remains a decision topic until evals justify it. |

## Extension Rule

Every extended concept should state which main-track block, capability, or milestone it
extends. If that prerequisite evidence does not exist yet, return to
`../main-track/milestone-1-45-hour-map.md` and finish the core artifact first.

## Rule

Do not use this folder to avoid the main path. Use it to deepen a concept only
after the related main-track artifact, tests, and explanation already exist.
