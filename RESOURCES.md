## Knowledge

- [Local: Main Track 30-Day Core](curriculum/main-track/README.md)
  The active learning route for Course 1. Use for: day-by-day sequencing, required evidence, milestone gates, and the core job-readiness path.
- [Local: 30-Day Core Map](curriculum/main-track/30-day-map.md)
  The daily evidence contract. Use for: choosing the next smallest lesson, protecting scope, and deciding what proof a session should leave behind.
- [Local: Main Track Scope Guards](curriculum/main-track/scope-guards.md)
  The core-versus-extended decision rule. Use for: preventing premature deep dives into frameworks, fine-tuning, multi-agent systems, or production platforms.
- [Local: Extended Concepts](curriculum/extended-concepts/README.md)
  The delayed-depth shelf. Use for: choosing follow-up labs after the main-track milestone evidence exists.
- [OpenAI API Platform Documentation](https://developers.openai.com/api/docs)
  Official OpenAI developer docs for model calls, structured output, tools, and agentic workflows. Use for: current API behavior and provider-boundary decisions.
- [OpenAI Agents SDK Guide](https://developers.openai.com/api/docs/guides/agents)
  Official guide for code-first agents, tools, handoffs, approvals, tracing, and state. Use for: understanding when an application-owned workflow should grow into an agent runtime.
- [Model Context Protocol Introduction](https://modelcontextprotocol.io/docs/getting-started/intro)
  Official MCP introduction. Use for: understanding why tools, resources, and prompts need explicit contracts between AI applications and external systems.
- [Model Context Protocol Specification](https://modelcontextprotocol.io/specification/2025-06-18)
  Official MCP specification. Use for: precise tool/resource/prompt boundaries and protocol vocabulary.
- [pytest Documentation](https://docs.pytest.org/)
  Official testing documentation. Use for: test-first implementation, focused failure diagnosis, fixtures, and regression checks.
- [FastAPI Testing Documentation](https://fastapi.tiangolo.com/tutorial/testing/)
  Official FastAPI testing guide. Use for: local API/service-boundary tests in the production-shaped app phase.
