# Curriculum Planning

This is the only active planning home for the AI Engineering Library.

## Maintained Contract

| File | Responsibility |
| --- | --- |
| `ROADMAP.md` | milestone philosophy, sequence, scope, and current priorities |
| `SPEC.md` | curriculum authoring and evidence contract |
| `CURRICULUM_REVIEW.md` | current review verdict, proof, gaps, and next actions |
| `docs/pedagogy-methodologies-research.md` | supporting teaching-method research |
| `implementation-notes/` | instructor-only reference and validation notes |

Learner-facing route contracts live beside the curriculum:

- `../../../curriculum/LEARNER_JOURNEY_MAP.md`
- `../../../curriculum/main-track/milestone-1-45-hour-map.md`
- `../../../curriculum/main-track/milestones.md`
- `../../../curriculum/main-track/scope-guards.md`
- `../../../LEARNER_READY_MATRIX.md`

When a planning statement conflicts with a learner route contract, update both
in the same change. Do not add a pointer file or a second roadmap.

## Local-Only Inputs

The ignored `books/`, source-material, generated corpus, old guides, historical
reports, and future-platform notes may exist in a maintainer workspace. They
are research inputs, not committed requirements. Promote only a concise,
source-backed decision into the maintained contract.

## Planning Rules

- Milestones are sequential capability gates.
- Engineering layers deepen horizontally inside each milestone.
- Milestone 1 stays within 40 planned hours plus five recovery hours.
- Existing folders do not become required merely because they exist.
- Stable learner folder names change only through an explicit migration.
- Git history is the historical ledger; planning files describe current truth.
- A new topic must replace scope, change the cumulative artifact, and improve a
  named evidence gate.
- Hosted platform work, advanced autonomy, fine-tuning, and scale remain
  deferred until the preceding capability evidence exists.
