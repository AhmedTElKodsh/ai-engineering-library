# Mission: Job-Ready AI Engineering

## Why

I want to become job-ready in AI Engineering by building real Business AQL and FinAgent-style products, not by passively watching AI generate code. The goal is to develop enough technical judgment to build, test, evaluate, explain, and improve agentic systems with clear evidence.

## Success looks like

- I can build a bounded AI workflow with deterministic code, model boundaries, tools, retrieval, evaluation, and traceable failure behavior.
- I can explain the architecture and tradeoffs of a FinAgent-style or Business AQL-style product to an engineer or hiring reviewer.
- I can use AI as a tutor and reviewer while still writing, testing, and defending the implementation myself.
- I can distinguish core job-readiness work from advanced topics that belong in extended study.

## Constraints

- Use the existing `curriculum/main-track/` as the active learning route.
- Use `curriculum/extended-concepts/` only after the related main-track evidence exists.
- Keep each learning session evidence-based: code, tests, traces, notes, or explanations.
- Prefer small, reviewable steps over large AI-generated solutions.

## Out of scope

- Chasing every new AI framework before the core engineering loop is reliable.
- Treating fine-tuning, multi-agent systems, or enterprise deployment as prerequisites for the first job-ready portfolio.
- Producing finished project code without learner understanding, tests, and explanation.
